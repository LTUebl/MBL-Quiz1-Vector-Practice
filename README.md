# BME 3303 Biomechanics - Quiz #1 Vector Practice

Interactive web application for **Lawrence Technological University BME 3303 Biomechanics** students to practice vector physics and biomechanics practice problems from Quiz #1.

## 🚀 Live Interactive Web App
Access the live deployed interactive web application via GitHub Pages:
**[https://LTUebl.github.io/MBL-Quiz1-Vector-Practice/](https://LTUebl.github.io/MBL-Quiz1-Vector-Practice/)**

---

## ✨ Features
1. **Interactive Vector Visualizations**: Real-time SVG canvas for each problem displaying force vectors, angles, component lines, and anatomical joint models.
2. **Dynamic Control Sliders**: Sliders to modify vector magnitudes, angles, masses, and marker coordinates.
3. **Step-by-Step Solution Calculator**: Live recalculated intermediate mathematical steps and final answer box.
4. **Beginner Hints**: Intuitive, step-by-step strategy tips tailored for introductory biomechanics students.
5. **Original Quiz Diagrams**: Embedded original problem figures from `MBL_PracticeProblems_Quiz1.docx` for reference.
6. **Responsive Layout & Navigation**: Previous/Next navigation arrows, quick-jump problem pills (`P1`–`P6`), and keyboard arrow key support.

---

## 📚 Problems Included
- **Problem 1**: 3D/2D Force Acceleration on a Ball ($m$, $\vec{F}_1, \vec{F}_2, \vec{F}_3, \theta_2$)
- **Problem 2**: Kinematic Elbow Flexion Angle from Marker Positions ($P_{shoulder}, P_{elbow}, P_{wrist}$)
- **Problem 3**: Patellofemoral Joint Reaction Force ($Q, P, \theta_{flexion}$)
- **Problem 4**: 2D Resultant & Reaction Force for Two Angled Forces ($F_1, F_2, \alpha, \beta$)
- **Problem 5**: Neck Joint Normal ($F_{Jn}$) & Shear ($F_{Jt}$) Reaction Force Components ($F_J, \beta$)
- **Problem 6**: Leg Traction Cable Tension Reaction Force ($T, \theta$)
